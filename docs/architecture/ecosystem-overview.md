# InsightForge Ecosystem Overview

## Vision

InsightForge is a self-hosted ecosystem combining AI infrastructure, financial intelligence, automation, analytics, and infrastructure observability.

The ecosystem is designed around three independent but connected repositories.

---

## Repository Structure

```text
InsightForge
│
├── insightforge-ai
│   Infrastructure Platform
│
├── insightforge-intelligence
│   Financial & Analytics Intelligence
│
└── insightforge-infra
    Documentation & Operations
```

---
